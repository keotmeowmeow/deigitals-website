# deigitals.co

Personal brand site for Claire Dei. One page, plain HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## Editing

- **Text:** open `index.html`, click the pencil icon, edit, and commit. The live site updates in about a minute.
- **Photos:** replace the files in `images/` using the same file names.
- **Tool logos:** files live in `logos/`. Add a new logo there, then add it to the tools list in `index.html`.
- **Work buttons:** search `index.html` for `wcard` to change the three links.
- **Contact links:** search `index.html` for `id="contact"`.
